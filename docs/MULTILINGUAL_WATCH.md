# Мультиязычные комнаты AniWatch

Экспериментальная ветка `experiment/multilingual-watch`, [PR №131](https://github.com/quvok/Aniwatch0/pull/131).

## Как пользоваться

1. Выбери **Русский** или **Español latino** в шапке. Переключатель также доступен в профиле и комнате. Язык интерфейса и предпочитаемый язык озвучки хранятся отдельно.
2. Ведущий открывает комнату и выбирает серию. Второй участник открывает приглашение и выбирает **AnimeAV1**. При неоднозначном совпадении можно подтвердить тайтл вручную. Вводить URL видео не требуется.
3. Если AnimeAV1 отдаёт DUB, он выбран первым. SUB расположен отдельно. Список видеосерверов показывает, какие варианты поддерживают только встраивание.
4. При различии версий участник может сдвинуть позицию на −5, −1, +1 или +5 секунд либо поставить видео в нужный момент и нажать **Привязать к позиции ведущего**. Смещение хранится для серии, провайдера и конкретного сервера или озвучки. Разница длительности от 10 секунд отображается в комнате.
5. Включи перевод входящих сообщений при необходимости. Переведённое сообщение сохраняет доступ к оригиналу. При отключении уже показанные сообщения снова отображаются в оригинале.

## Контракт AnimeAV1 и совместимость

Проверены реальные ответы `/search?query=Naruto`, `/anime/naruto`, `/anime/naruto-shippuuden`, `/anime/naruto/1` и `/anime/dragon-ball-daima/1`. Поиск возвращает `data.media`, карточка содержит `malId`, `year`, `type`, `alternative_titles` и нумерованные `episodes`. Ответ серии содержит `number` и `embeds` с метками `DUB` и `SUB`. Отдельный код языка или региона API не отдаёт. DUB показан в интерфейсе испаноязычного каталога как испанская озвучка.

MAL ID позволяет различать продолжения и спин-оффы. Без него автоматический выбор требует уникального совпадения названия, года, формата и числа серий. Код проверяет явный номер сезона, если он есть в обоих источниках. При неоднозначности остаётся ручной выбор. Связь с подтверждённым slug хранится локально. В испанской карточке отображаются заголовок и синопсис AnimeAV1, когда найдено надёжное совпадение.

| Сервер или формат | Результат |
| --- | --- |
| StreamTape | Документирует Embedly Player.js для play, pause и seek. AniWatch проверяет origin, источник сообщения, событие `ready` и объявленные возможности. Скорость через этот протокол недоступна. Проверенный настоящий embed вернул HTTP 403 с `x-openai-site-blocked` в среде прогона. Воспроизведение реального embed и его управление не подтверждены. |
| HLS в ответе Naruto | Это страница `player.zilla-networks.com/play/…`. Она вернула HTTP 403 с `X-Frame-Options: SAMEORIGIN`. Прямого URL плейлиста в ответе нет. |
| UPNShare, Voe, Byse, YourUpload, MP4Upload | Проверенные DUB-ссылки вернули HTML с HTTP 200. Ответ страницы не доказывает воспроизведение. Для этих URL не подтверждён документированный интерфейс всех нужных команд. AniWatch обозначает их как источники без синхронизации. |
| Прямой MP4 или HLS | HTML5 и HLS.js умеют синхронизировать такие источники. Требуется опубликованный провайдером HTTPS URL с разрешённого хоста. В проверенных ответах AnimeAV1 этих URL не было. MP4 прошёл браузерную проверку с управляемым тестовым видео. |

Встроенные страницы открываются в ограниченном iframe. Для просмотра без автоматической синхронизации доступны исходная ссылка, позиция ведущего для ручной сверки и переход на Kodik с русской озвучкой. Для стабильной кросс-языковой комнаты подойдёт поставщик с разрешёнными прямыми MP4/HLS либо iframe с документированным API. Текущий адаптер не извлекает поток из HTML-страницы или секции загрузок.

- [Документация AnimeAV1](https://animeav1.ahmedrangel.com/)
- [Документация StreamTape](https://adblockstrtape.link/api)
- [Спецификация Embedly Player.js](https://github.com/embedly/player.js/blob/master/SPEC.rst)

## Официальный YouTube

Для *Beyblade X* (Shikimori 56566) серии 1 и 2 доступны через канал BEYBLADE Español – Canal Oficial. AniWatch связывает номера серий с конкретными ID официальных публикаций. На этих сериях выбор испанского звука предпочитает YouTube. Kodik остаётся доступен для русской озвучки.

Реальные публикации и их oEmbed проверены. Команды запуска, паузы, перемотки, смены скорости, переход на следующую серию и обработка отказа во встраивании проверены с имитацией интерфейса YouTube. Возможность просмотра зависит от прав на встраивание и региона зрителя. При расхождении монтажей остаётся ручная привязка по времени.

## Синхронизация и данные

Комната передаёт идентификатор аниме, номер серии, позицию, длительность, состояние воспроизведения, скорость, буферизацию, время отправки и номер последовательности. Источник, язык и идентификатор озвучки остаются у участника. Клиенты проверяют типы и диапазоны полей, порядок сообщений, возраст состояния и ответ на запрос часов.

До 250 мс коррекция позиции не требуется. При 250–1000 мс поддерживающие её плееры временно меняют скорость. Для расхождения больше 1000 мс выполняется перемотка с ограничением частоты. Kodik сообщает позицию с округлением до секунды, поэтому небольшие расхождения на паузе нельзя измерить точно. При буферизации ведущего прогноз времени останавливается. Плеер участника может потребовать нажатия ▶ из-за политики автоматического воспроизведения.

Гостевые комнаты используют существующие Supabase Broadcast и Presence по коду комнаты. Проверка формы события защищает от некорректных данных. Текущий публичный канал не удостоверяет роль отправителя, поэтому известный код комнаты даёт возможность имитировать ведущего. Для недоверенных участников потребуется авторизация Realtime на сервере или подпись состояния. Оба участника эксперимента должны использовать одну версию клиента комнаты.

## Перевод и настройки Supabase

Браузерный Translator API используется при наличии модели. На мобильных браузерах обычно нужен серверный перевод. Включив перевод, участник разрешает отправку текста входящих сообщений настроенному провайдеру, если локальная модель недоступна. Оригинал остаётся в чате, перевод кэшируется только в текущей вкладке. Серверный путь требует входа в аккаунт. Без модели или настроенного сервера пользователь увидит оригинал.

Для тестового проекта Supabase примени миграцию `20261128010000_watch_language_preferences.sql` и разверни `translate-room-chat`. Миграция добавляет пользовательские языковые настройки с RLS и лимиты 15 запросов в минуту на аккаунт и 120 на проект. Edge Function отдельно проверяет JWT пользователя. Настройки окружения:

| Переменная | Значение |
| --- | --- |
| `CHAT_TRANSLATOR_PROVIDER` | `cloudflare`, `deepl` или `google` |
| `CHAT_TRANSLATOR_API_KEY` | Секрет выбранного сервиса в Supabase |
| `CHAT_TRANSLATOR_CLOUDFLARE_ACCOUNT_ID` | ID аккаунта Cloudflare для провайдера `cloudflare` |
| `CHAT_TRANSLATOR_DEEPL_PAID` | `true` для платного endpoint DeepL |
| `CHAT_TRANSLATOR_ALLOWED_ORIGINS` | Список дополнительных origin тестовых сборок через запятую |

Cloudflare Workers AI использует модель `@cf/meta/m2m100-1.2b`. Для тарифа Workers Free нужен API-токен с доступом **Workers AI Read** к выбранному аккаунту. Лимит бесплатного тарифа сбрасывается ежедневно. При недоступности API чат показывает исходное сообщение.

- [Workers AI REST API](https://developers.cloudflare.com/workers-ai/get-started/rest-api/)
- [Тарифы Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/)

## Воспроизводимые проверки

```bash
npm ci
npx playwright install chromium
npm run check
npm run build
npm run test:e2e -- --workers=2
ANIMEAV1_LIVE=1 npm run test:e2e -- tests/animeav1.live.spec.js --project=desktop
```

Браузерный набор проверяет два независимых контекста, RU Kodik и ES AnimeAV1, загрузку MP4, Player.js, выбор DUB/SUB, паузу, воспроизведение, перемотку, скорость, восстановление соединения, несовпадающие длительности, смещения, следующую серию, локализацию, перевод в обе стороны, ошибки перевода и экранирование чата. В нём используются фикстуры внешних API и Realtime. Отдельный live-тест проходит по актуальному каталогу AnimeAV1, проверяет два разных тайтла и DUB/SUB на реальном ответе серии.

### Результаты прогона

| Проверка | Результат |
| --- | --- |
| Chromium desktop и Android Pixel с имитацией внешних сервисов | 25 тестов прошли. Live-тест вынесен в отдельный запуск. |
| Реальный AnimeAV1 API | 1 тест прошёл. Подтверждены Naruto и Naruto Shippuuden с разными MAL ID и метки DUB/SUB серии Naruto. |
| WebKit с профилем iPhone 15 | Прошли переключение языка, загрузка испанского каталога, подключение к комнате с имитацией Realtime, отображение оригинала при недоступном переводчике и проверка ширины. Физическое устройство не использовалось. |
| PostgreSQL, миграция и квота | Миграция применилась локально. Проверены чтение и запись собственного языка, запрет доступа к настройкам другого аккаунта и отказ на 16-м запросе за минуту. |
| Код и сборка | `npm run check` и `npm run build` прошли. |

Сквозной прогон с настоящими Kodik, AnimeAV1 и Supabase Realtime остаётся открытым. Локализация охватывает навигацию, основные страницы и состояния комнаты. Редкие сообщения старых компонентов и данные без проверенного испанского перевода могут остаться на исходном языке.
