# AniWatch

Фронтенд аниме-платформы на GitHub Pages. Основные разделы: главная, каталог, персональные рекомендации, страницы тайтлов, демо-плеер, история просмотра, избранное, списки, профиль и совместный просмотр.

## Запуск локально

Открой `index.html` или запусти:

```bash
python3 -m http.server 8000
```

## Где что находится

- `js/app.js` — интерфейс, каталог, история, рекомендации, локальные оценки и профиль.
- `js/config.js` — публичная настройка WebSocket-сервера комнат.
- `css/style.css` — оформление.
- `server/` — отдельный Node.js WebSocket-сервер для комнат и чата.

## Хранение данных

История, прогресс, избранное, личные оценки, отзывы и профиль пока хранятся в браузере пользователя (localStorage / IndexedDB). Они не синхронизируются между устройствами и не видны другим пользователям.

## Совместный просмотр

Клиент комнат подключается к WebSocket-серверу из `server/`. Перед использованием нужно развернуть его и прописать адрес в `js/config.js`. Полная инструкция: [server/README.md](server/README.md).

Сервер синхронизирует состояние демонстрационного таймера и сообщения чата. Настоящий видеопоток ещё не подключён, поэтому синхронизация не заменяет общий источник видео.

## Внешние данные

- AniList GraphQL — каталог, постеры, рейтинги, жанры и расписание.
- Shikimori — русские названия и дополнительные данные.
- Другие API используются для уточнения количества серий.

## Что потребуется для полноценного запуска платформы

- Backend и база данных для настоящих аккаунтов, общих отзывов и облачной синхронизации.
- Развёрнутый WebSocket-сервер для комнат.
- Законный видеохостинг или собственные источники видео.
