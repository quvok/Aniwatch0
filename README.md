# AniWatch

Фронтенд аниме-платформы: главная, каталог, поиск, жанры, страницы тайтлов, избранное, демо-плеер, чат и профиль. Данные демо-режима хранятся в localStorage.

## Запуск
Откройте `index.html` или запустите `python3 -m http.server 8000`. Сборка не нужна.

## Структура
- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/app.js` — логика приложения и работа с API

## API и ограничения
Проект использует AniList GraphQL и Shikimori API для получения данных о тайтлах. Если API недоступны, используется демо-каталог. Видеоплеер и чат являются демонстрационными: для реального видео, синхронных комнат, аккаунтов и постоянного хранения данных потребуется серверная часть. Используйте только видео и изображения, на которые у вас есть права.
