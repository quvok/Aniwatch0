# AniWatch

Фронтенд аниме-платформы: главная с баннером и «Продолжить просмотр», каталог (жанры, сортировка, поиск), страницы тайтлов (серии, оценка, избранное), демо-плеер, чат, комнаты, профиль. Данные хранятся в localStorage.

## Запуск
Откройте `index.html` или выполните `python3 -m http.server 8000` и зайдите на `http://localhost:8000`. Сборка не нужна. Открывать сайт стоит через сервер: модули ES (`type="module"`) и сервис-воркер не работают с `file://`.

## Страницы
Сайт состоит из отдельных HTML-страниц. Параметры передаются в адресе (`?id=…`), а не через `#`.

| Страница | Адрес | Что показывает |
|---|---|---|
| Главная | `index.html` | баннер, «Продолжить просмотр», подборки, жанры |
| Каталог | `catalog.html?q=…&g=…&y=…&status=…&format=…&sort=…&score=…` | поиск и фильтры, адрес можно скопировать и отправить |
| Эфир | `schedule.html` | расписание выхода серий на 7 дней |
| Избранное | `favorites.html` | избранные тайтлы |
| Мои списки | `lists.html` | смотрю / запланировано / просмотрено / брошено |
| Вместе | `together.html` | комнаты для совместного просмотра |
| Профиль | `profile.html` | ник, акцентный цвет, резервная копия |
| Тайтл | `anime.html?id=…` | описание, серии, трейлер, связанные тайтлы |
| Плеер | `watch.html?id=…&ep=…` | серия и демо-плеер |
| Случайное | `random.html` | выбирает тайтл и перенаправляет на `anime.html` |

Старые ссылки вида `index.html#title-12` продолжают работать: `legacyRedirect()` в `js/core/router.js` переводит их на новые страницы.

### Как это устроено
- Каждая страница — тонкий HTML-файл с `<body data-page="…">`. Общий код (`js/app.js`) смотрит на `data-page` и рисует нужный экран.
- Шапка и меню — один компонент `js/components/site-header.js`, поэтому в HTML-файлах её нет.
- Таблица страниц (`PAGES`) и функции `pageUrl`, `titleUrl`, `watchUrl` лежат в `js/core/router.js`. Ссылки в шаблонах строятся только через них.
- Страница загружается заново при каждом переходе. Карточки, которые пользователь только что видел, передаются следующей странице через `sessionStorage` (ключ `aw.items`), поэтому тайтл открывается сразу. Если ссылку открыли напрямую, тайтл подгружается по `id`.
- **Как добавить страницу:** создайте `<имя>.html` по образцу любой существующей, добавьте строку в `PAGES`, функцию-экран в `V` (`js/app.js`) и имя файла в `SHELL` в `sw.js`. Команда `node scripts/check-pages.mjs` проверит всё это (она же запускается в GitHub Actions).

## Где что менять
- `js/app.js` — массив `D` (тайтлы), `V.*` (экраны), `DUR` (длина серии в демо-плеере)
- `js/core/router.js` — список страниц и адреса
- `js/components/site-header.js` — шапка и меню
- `css/style.css` — стили; цвета в `:root` (`--ac` — акцент)

## Что подключить для реального сайта
- Видео: заменить блок `.player` на `<video>`/HLS-плеер со своим источником (только контент, на который у вас есть права)
- Совместный просмотр: Supabase Realtime Broadcast/Presence для комнат, списка участников, чата и синхронизации состояния таймлайна. Для реального видео всё ещё нужен легальный видеопоток и настоящий HTML5/HLS-плеер
- Каталог и аккаунты: API и база данных вместо массива `D` и localStorage

## Реальные данные (подключено)
- **AniList** (`https://graphql.anilist.co`, публичный GraphQL без ключа): используется для постеров и баннеров каталога по MAL ID, расписания выхода серий и данных о следующем эпизоде/трейлере. Запросы идут напрямую из браузера через POST и последовательно с интервалом 2,1 секунды. Текущий лимит API по документации AniList — временно 30 запросов/мин (обычный лимит — 90). Обработчик учитывает HTTP 429 и GraphQL-ошибку `Too Many Requests`, использует `Retry-After`/`X-RateLimit-Reset`, а если заголовки недоступны браузеру — ждёт 60 секунд.
- **Shikimori** (`https://shikimori.io/api/animes`): источник каталожных данных, MAL ID и русских названий. Русское описание подгружается отдельно на странице тайтла. Shikimori не используется как источник изображений каталога.
- Если API недоступен, сайт показывает демо-тайтлы из массива `D`.
- Для продакшена вынесите запросы на свой сервер с кэшем, чтобы не зависеть от лимитов и CORS.
- Перед запуском проверьте условия использования AniList и Shikimori. Картинки принадлежат правообладателям.

## v2
- **Каталог** (`V.catalog` (`catalog.html`)): поиск и метаданные из Shikimori; изображения карточек запрашиваются исключительно из AniList GraphQL по MAL ID. Постеры Shikimori не используются даже как запасной вариант. Если у тайтла нет MAL ID или соответствия в AniList, показывается штатная заглушка. Доступны фильтры жанр/год/статус/формат/сортировка и постраничная загрузка.
- **Эфир** (`V.schedule` (`schedule.html`)): расписание серий на 7 дней, время по часам устройства, таймер до выхода. На странице тайтла показывается таймер следующей серии.
- **Трейлеры**: официальный трейлер из AniList (YouTube/Dailymotion) встраивается на страницу тайтла.
- **PWA**: `manifest.webmanifest`, `sw.js`, иконки в `icons/`. Приложение ставится на экран телефона, оболочка (все HTML-страницы и модули) и картинки кэшируются; офлайн открывается закэшированная страница. При изменении файлов оболочки увеличивайте версию `V` в `sw.js` (текущая версия — `aw-v51`), чтобы браузер удалил старый кэш оболочки и загрузил обновления.

## Разделение источников данных
- **AniList** — источник подборок и списков тайтлов (тренды, популярное, онгоинги, каталог рекомендаций), постеров и баннеров. Связь с Shikimori выполняется через MAL ID.
- **Shikimori** — источник русских и альтернативных названий и описаний. Метаданные подгружаются пачками до 50 MAL ID и кэшируются в браузере на 7 дней; страница тайтла использует тот же источник.
- Если у тайтла нет MAL ID или соответствия на Shikimori, остаются доступные названия AniList; если нет соответствия на AniList, карточка использует штатную заглушку изображения.

## Совместный просмотр
- Откройте раздел «Вместе», выберите тайтл и создайте комнату. Ссылка-приглашение содержит случайный 8-символьный код комнаты.
- Друзья открывают ссылку или вводят код на странице «Вместе». После подключения комната синхронизирует выбранное аниме, серию, состояние воспроизведения, позицию и скорость; чат и присутствие участников работают через Supabase Realtime.
- Сообщения чата и состояние комнаты передаются как временные Broadcast-события и не сохраняются в базе данных. Код комнаты действует как ссылка-приглашение; не публикуйте его в открытом доступе.
- **Ограничение текущей версии:** видеоплеер AniWatch остаётся демонстрационным таймером. Синхронизируется именно его таймлайн и управление, а не реальное видео. Для полноценного просмотра нужен источник видео, на распространение которого есть права, и интеграция HTML5/HLS-плеера.
- Для работы комнат в Supabase должен быть доступен Realtime и разрешены публичные каналы (Allow public access). Клиенты используют только publishable key; секретные ключи на фронтенд не добавляются.
