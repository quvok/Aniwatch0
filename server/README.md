# AniWatch room server

Этот небольшой Node.js сервер обеспечивает реальные комнаты, чат и синхронизацию демонстрационного плеера между браузерами. Пока сервер не развёрнут, совместный просмотр на GitHub Pages не будет подключаться.

## 1. Развернуть сервер

Нужен любой хостинг, который запускает постоянный Node.js процесс и поддерживает WebSocket. В качестве корневой директории укажи `server`, команда запуска — `npm start`.

Переменные окружения:

- `PORT` — порт (хостинг обычно задаёт сам).
- `ALLOWED_ORIGINS` — разрешённые сайты через запятую. Для текущего GitHub Pages укажи `https://quvok.github.io`.

После запуска проверь адрес `https://АДРЕС-СЕРВЕРА/health`. Ответ должен содержать `"ok":true`.

## 2. Подключить сайт

Открой `js/config.js` и укажи WebSocket URL своего сервера:

- `wss://АДРЕС-СЕРВЕРА` для HTTPS-хостинга.
- `ws://localhost:8080` только для локальной разработки.

Пример:

```js
window.ANIWATCH_CONFIG={websocketUrl:"wss://your-room-server.example"};
```

После этого обнови сайт и создай комнату. Отправь шестизначный код другу.

## Ограничения текущей версии

- Комнаты хранятся в памяти процесса и исчезают после перезапуска сервера.
- До 8 участников в комнате.
- Нет регистрации и проверки личности — любой, у кого есть код, может войти.
- Синхронизируется состояние демонстрационного таймера AniWatch. Настоящий видеопоток ещё не подключён.
- Это не видеотрансляция: каждому участнику нужен собственный источник видео, когда он появится.

Не публикуй секретные ключи в `js/config.js`. В нём должен быть только публичный URL WebSocket-сервера.
